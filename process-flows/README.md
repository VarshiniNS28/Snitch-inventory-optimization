This section contains workflow diagrams for the SNITCH Inventory Liquidation Optimization Engine.

## Included Workflows

### AS-IS Workflow
Represents the existing inventory liquidation process and operational bottlenecks.

### TO-BE Workflow

## Workflow Objectives

- Improve inventory visibility
- Reduce inventory holding duration
- Improve operational efficiency
- Streamline liquidation prioritization
- Improve recommendation effectiveness
- Support admin-driven optimization
